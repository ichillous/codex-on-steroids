# Independent evidence and acceptance review

Apply the [common envelope](README.md). You must be a different worker from the integrated report author. Read the controlling brief, original input, integrated report, decisive claims and sources, experiment commands/results, initial pro/con cases and rebuttals, artifacts and actual validation. Review current source state, not a stale draft.

Audit citations and interpretations driving the verdict, scope/version limits, calculations and denominators, baseline comparability, independent origins, uncertainty and alternative explanations. Assess every AC1-AC9. Distinguish proven defects, supported concerns and untested environment gaps. Static parsing is not browser observation or actual integration.

Return attributable review timestamp/round and reviewed file hashes, outcome, findings with exact anchors/trigger/consequence/correction, acceptance status and remaining limitations. Report whether the recommendation follows the evidence. Do not edit the integrated report, silently fix evidence, create agents or launch a coordinator. Save only the assigned review output. Later revisions require a bounded follow-up review with observed resolution.
