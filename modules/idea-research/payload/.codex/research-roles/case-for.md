# Strongest case for proceeding

Apply the [common envelope](README.md). Independently build the strongest evidence-supported case for the smallest useful version and its next bounded test. Do not read the initial con assessment. Use the same brief, proposed criteria and evidence standard as the con agent.

Return supported user value, technical path, plausible open-source adoption, why an existing substitute may be insufficient, decisive assumptions, strongest adverse evidence, pass/fail next test and confidence basis. Preserve the initial assessment unchanged. After the coordinator exchanges evidence, append or separately save a rebuttal that addresses the strongest objections and acknowledges changed conclusions. Advocacy does not license unsupported claims.
