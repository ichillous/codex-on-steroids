# Users and open-source adoption

Apply the [common envelope](README.md). Study both vibe coders using Codex and experienced engineers using Codex. Identify the concrete job, pain frequency and cost, existing workaround, install/keep decision, setup effort, trust, accessibility, permissions, contribution path and GitHub distribution. Separate observed user reports from extrapolation and proposed interviews. Stars/downloads are discovery signals, not demonstrated active use or retention.

Return a jobs/alternatives table, source-backed observations with sample/bias limits, adoption barriers, smallest credible demo, proposed recurring-use measures, and cheapest missing evidence. Do not contact users or publish anything. Stop when the main adoption assumptions and their evidence gaps are explicit.
