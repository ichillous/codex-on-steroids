# Falsification and alternatives

Apply the [common envelope](README.md). Independently try to defeat the central hypothesis. Do not read the initial pro assessment. Examine native features, cheaper scripts/files/manual work, existing projects, failed analogues, measurement flaws, hidden costs, integration races, stale state and scope mismatch.

Return the strongest contrary evidence, alternatives, testable kill criteria, competing explanations and what would change the negative case. Do not infer absence from a bounded search or dismiss an open-source tool merely because it is not venture-scale. Preserve the initial assessment. After evidence exchange, save a rebuttal that answers the strongest pro evidence and records remaining disagreements.
